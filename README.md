# 📧 User  Verification (Django)

This project is a simple **Django authentication system** with **email verification**.
When a user registers, a verification link is sent to their email. The account becomes active only after the email is verified.

## 🚀 Features

* 👤 User Registration
* 🔑 Login & Logout
* 🔒 Secure Authentication

## 🛠 Technologies Used

* Python 🐍
* Django 🌐
* HTML / CSS 🎨

## ⚙️ Installation

1️⃣ Clone the repository

```
git clone https://github.com/your-username/user-email-verification.git
```

2️⃣ Go to project folder

```
cd user-email-verification
```

3️⃣ Create virtual environment

```
python -m venv .venv
```

4️⃣ Activate virtual environment

Windows:

```
.venv\Scripts\activate
```

5️⃣ Install dependencies

```
pip install -r requirements.txt
```

6️⃣ Run migrations

```
python manage.py migrate
```

7️⃣ Start server

```
python manage.py runserver
```

## 🌐 Usage

* Register the verification link
